خيارات التثبيت والتشغيل

اختر الطريقة التي تناسبك: تجربة النظام كـ Live ISO من فلاشة أو تثبيته على نظام Arch الحالي.

قم بتحميل ملفات التوزيعة الرسمية للإصدار v2026.09.2 مباشرة من سيرفرات GitHub:

nooreldeanos-*.iso.00.part 1.76 GB • مباشر nooreldeanos-*.iso.01.part 1.36 GB • مباشر nooreldeanos-*.iso.sha256 101 Bytes • للتحقق

أمر حرق ملف الآيزو على الفلاشة في لينكس (تأكد من تحديد مسار الفلاشة الصحيح بدل sdX):

sudo dd bs=4M if=nooreldeanos-2026.09.21-x86_64.iso of=/dev/sdX status=progress oflag=sync
💡 يمكنك أيضاً استخدام برامج مثل BalenaEtcher أو Ventoy أو Rufus لحرق الملف بكل سهولة.

إذا كنت تملك نظام Arch Linux مثبت مسبقاً، يمكنك تحويله بضغطة زر إلى NooreldeanOS بكامل الثيمات والبرمجيات:

curl -fsSL https://raw.githubusercontent.com/coach-nooreldean/NooreldeanOS-Dotfiles/main/install.sh | bash

يقوم السكريبت تلقائياً بتثبيت الحزم الأساسية، إعداد Yay، نسخ الكونفجات، وتهيئة بيئة Hyprland ونظام الصوت بالكامل.

نظراً لحدود GitHub البالغة 2GB للملف الواحد، تم تقسيم الآيزو لجزئين. لدمجهم في ملف واحد:

على أنظمة Linux / macOS:
cat nooreldeanos-*.iso.*.part > nooreldeanos-2026.09.21-x86_64.iso
على أنظمة Windows (Command Prompt):
copy /b nooreldeanos-*.iso.00.part + nooreldeanos-*.iso.01.part nooreldeanos.iso
