EASY INSTALLATION

طرق التثبيت (سطر واحد فقط)

اختر الطريقة المناسبة لحالتك واستمتع بالنظام في دقائق معدودة.

bash installer

توزيعة مستقلة رسمياً وجاهزة للحرق على فلاشة USB: إقلاع حي فوري بـ Hyprland مع مثبت Calamares الرسومي الشهير ونواة linux-zen فائقة السرعة.

# لحرق الأسطوانة عبر التيرمينال (استبدل sdX بمسار فلاشة الـ USB):
sudo dd bs=4M if=NooreldeanOS-x86_64.iso of=/dev/sdX status=progress oflag=sync ⬇️ تحميل الـ ISO

1. مثبت Calamares

تثبيت رسومي بنقرات زر وتقسيم قرص تلقائي بدعم كامل للعربية.

2. نواة linux-zen

معدلة لتقليل زمن الاستجابة وتقديم أداء ألعاب وفيديو خارق.

3. إقلاع مباشر بـ Hyprland

تجربة النظام حياً بالكامل (Live Demo) فوراً من الفلاشة.

4. دعم كروت Nvidia

خيار إقلاع مخصص لتعريفات Nvidia الرسمية أو المعالجات المدمجة.

لو مسطب Arch Linux بالفعل، انسخ الأمر ده في التيرمينال وسيتكفل السكربت بتثبيت البرامج، أخذ باك أب من إعداداتك، وتحديث مسارات يوزرك أوتوماتيك:

git clone https://github.com/coach-nooreldean/NooreldeanOS-Dotfiles.git ~/NooreldeanOS-Dotfiles && cd ~/NooreldeanOS-Dotfiles && bash install.sh

1. فحص المستخدم

تعديل مسارات ملفات الكونفيج تلقائياً دون لمس أي كود.

2. نسخ احتياطي آمن

حفظ ملفاتك السابقة في مجلد ~/.NooreldeanOS-backup.

3. حزم Pacman + Yay

تثبيت البرامج الأساسية وحزم الـ AUR المطلوبة بسلاسة.

4. تفعيل الخدمات

ضبط ZRAM وشبكة UFW وجلسة Hyprland للتشغيل الفوري.

لو لسه محمل أسطوانة Arch Linux الرسمية (ISO) وعايز تفرمت الهارد وتنزل النظام بالكامل مع NooreldeanOS:

bash <(curl -sL https://raw.githubusercontent.com/coach-nooreldean/NooreldeanOS-Dotfiles/main/start.sh)

1. تقسيم القرص

تهيئة قطاعات EFI ونظام Btrfs/Ext4 بأمان.

2. تنزيل النواة

تحميل النواة ومستودعات Arch الرسمية بسرعة البرق.

3. إعداد الحساب

ضبط الشبكة والوقت وإنشاء حسابك الشخصي في خطوة واحدة.

4. إقلاع مباشر

إعادة تشغيل ودخول مباشر في واجهة SDDM Astronaut.

لو حابب تلغي التثبيت أو ترجع لإعداداتك القديمة زي ما كانت من الباك أب:

./uninstall.sh

السكربت هيسألك إذا كنت ترغب في إبقاء برامجك وتطبيقاتك الشخصية أو إزالتها واسترجاع ملفات الـ Dotfiles السابقة.

ENGINEERING & MODULARITY

المعمارية البرمجية للمشروع

مبني بنظام Modular Modules نظيف تحت lib/ مع نظام مصيدة الأخطاء و ShellCheck CI.

NooreldeanOS-Dotfiles/ ├── install.sh # نقطة الإدخال الرئيسية للتثبيت (Entry Point) ├── post-install.sh # يعمل داخل chroot عند تثبيت النظام من الصفر ├── start.sh # سكريبت التقسيم والتثبيت الكامل لـ Arch Linux ├── uninstall.sh # منطق إزالة التثبيت واستعادة النسخ الاحتياطية ├── lib/ # المجلد الأساسي للـ Modules المعيارية │ ├── config.conf # ملف الإعدادات العامة والمتغيرات الافتراضية │ ├── logger.sh # نظام الطباعة الملونة وتسجيل الأخطاء والـ Logs │ ├── core_install.sh # منطق تثبيت الحزم (pacman, yay, flatpak) │ ├── backup.sh # منطق أخذ النسخ الاحتياطية المؤرخة والآمنة │ ├── symlinks.sh # منطق توزيع وربط ملفات الإعدادات (Symlinks / Copy) │ └── services.sh # تفعيل خدمات النظام (systemd, ufw, docker, zram) └── .github/workflows/ # أتمتة الـ CI/CD (فحص ShellCheck ونشر التوثيق)

HELP & FAQ

الأسئلة الشائعة

إجابات سريعة وواضحة على أهم الاستفسارات.

هل يمكن تثبيته بجانب ويندوز (Dual Boot)؟ ➕
نعم بالتأكيد! استخدم الطريقة الأولى (التثبيت على نظام Arch شغال بالفعل) لتثبيت الدوت فايلز دون المساس بقطاعات ويندوز. لا تستخدم start.sh لأنه مخصص لفرمتة الهارد كاملاً من أسطوانة ISO.
أين أجد ملفات الإعدادات والكونفيج لتعديلها؟ ➕
توجد جميع الإعدادات تحت ~/.config/ (Hyprland في hyprland.lua، الشريط في waybar/config، والطرفية في kitty/kitty.conf).
كيف أغير مواقيت الصلاة لتناسب مدينتي؟ ➕
يمكنك تعديل إحداثيات خط الطول والعرض أو اسم مدينتك من خلال ملف ~/.config/waybar/scripts/prayer_times.sh بكل بساطة.
كيف أضيف خلفياتي الخاصة لمبدل Super + W؟ ➕
ضع أي صور أو خلفيات بدقة عالية داخل مجلد ~/wallpapers/ وستظهر فوراً في شبكة الـ Rofi عند الضغط على Super + W.
