تنبيه توافق النظام

هذه الـ Dotfiles وسكربت التثبيت مصممة حصرياً لتوزيعة Arch Linux أو التوزيعات المبنية عليها (مثل EndeavourOS). تشغيلها على أوبونتو أو فيدورا قد يؤدي إلى تعارض في الحزم!

أبرز مميزات النظام

بنية معمارية متطورة تدمج بين الجمال والأداء العالي

🪟

Hyprland Wayland Compositor

مدير نوافذ سلس وسريع جداً مع رسوم متحركة ناعمة (macOS-like curves)، تقسيم ديناميكي ذكي، وقواعد عائمة للنوافذ المنبثقة والـ PiP.

📊

Waybar تفاعلي غني

شريط علوي زجاجي يعرض درجات حرارة كرت الشاشة (Nvidia/AMD)، سرعة الشبكة، استهلاك الذاكرة، والطقس الحي في مدينتك.

🕌

مواقيت الصلاة والأذان

تكامل مباشر مع مواقيت الصلاة في شريط Waybar مع التنبيه بالأذان فور حلول الوقت، وإمكانية إيقاف الصوت بضغطة زر يمين.

🎨

مزامنة ألوان ذكية (Pywal)

بمجرد تغيير الخلفية، يقوم النظام تلقائياً بتوليد باليت ألوان متناسقة وتطبيقها على Kitty و Rofi و Waybar وثيمات النظام.

⚡

طرفية مطورين متكاملة

محاكي Kitty مع خط JetBrainsMono Nerd Font، موجه Starship السريع، أداة Zoxide للقفز الفوري، وبحث FZF الذكي واختصارات Git و Flutter.

🧹

أداة صيانة النظام (sys-clean)

أداة CLI مستقلة تنظف كاش الباكمان، تحذف الحزم اليتيمة، تفرغ سجلات النظام، وتشغل fstrim لتحسين سرعة وعمر الـ SSD.
