تكامل Pywal التلقائي والجماليات الزجاجية الشاملة

مجرد ما تختار أي خلفية، يولد النظام لوحة ألوان ديناميكية ويطبقها في أجزاء من الثانية على Hyprland، شريط Waybar، مركز SwayNC، قائمة Rofi، محاكي Kitty، شاشة القفل Hyprlock، وتطبيقات Qt بدون الحاجة لأي إعادة تشغيل!

الألوان تتناغم أوتوماتيكياً عبر الـ Pywal Daemon:
🛡️

حماية Btrfs والدرع الفوري (noor-snap)

لقطات نظام لحظية لا تستهلك أي مساحة زائدة. استرجع نظامك كاملاً بضغطة زر عبر Super + Shift + S أو مباشرة من قائمة إقلاع GRUB لو تعطل أي تحديث.

noor-snap • Btrfs Subvolumes • GRUB Auto-Entry
🚀

نواة Linux-Zen وضغط الذاكرة ZRAM

كيرنل مخصص لتقليل الـ Latency ورفع استجابة النظام تحت الضغط، مع تفعيل ضغط الذاكرة ZRAM بخوارزمية zstd لتشغيل الألعاب وبرامج المونتاج بلا اختناق.

linux-zen 6.x • zstd compressed swap • High Tickrate
🎮

كشف وضبط كروت الشاشة التلقائي (GPU Auto-Tuning)

فحص تلقائي أثناء الإقلاع يتعرف على بطاقات Nvidia و AMD و Intel، ويفعل تعريفات Proprietary مع متغيرات WLR_NO_HARDWARE_CURSORS وتسريع العتاد VA-API وحل مشاكل تمزق الإطارات بدون أي تدخل يدوي.

➜ Automatic Driver Detection Nvidia • AMD Radeon • Intel Iris/Arc
⚡

مبدل التردد الفوري (144Hz / 240Hz)

تحكم فوري بمعدل الإنعاش، دقة الشاشة، ومقياس الواجهة بنقرة زر عبر Super + Shift + D مع حفظ الإعدادات تلقائياً في monitors.conf.

Super + Shift + D ➜ Refresh & Resolution
🎧

مبدل مخارج الصوت والبلوتوث الذكي

تبديل فوري بين السماعات الخارجية، هيدست البلوتوث، وشاشات HDMI عبر Super + A بدعم محرك WirePlumber و PipeWire فائق النقاوة.

PipeWire • WirePlumber • Instant Bluetooth
🕌

أدوات إنتاجية وهوية إسلامية مدمجة

مواقيت صلاة وأذان دقيق مع زر كتم فوري من شريط المهام، مدير الحافظة CopyQ مع سجل نسخ متقدم عبر Super + V، أداة الصيانة الذكية clean، وشاشة إقلاع Plymouth فائقة النعومة بدون وميض.

Plymouth Dark Glow • CopyQ • SwayNC جاهز للعمل المباشر فور التثبيت
SYSTEM SPECIFICATIONS

المواصفات التقنية للتوزيعة

مكونات برمجية حديثة ومختارة بعناية لتحقيق أعلى معدل إطارات وأقل استهلاك للطاقة والذاكرة.

المكون الأساسي (Subsystem) الحزمة البرمجية (Package / Technology) الوظيفة والتحسينات المضافة (Enhancements)
قاعدة التوزيعة (Base OS) Arch Linux Rolling Release تحديثات متجددة مستمرة وأحدث الحزم من مستودعات Arch و AUR الرسمية.
النواة الافتراضية (Kernel) linux-zen 6.x نواة معدلة لتقليل زمن استجابة الجدولة (Scheduler Latency) وتحسين الألعاب.
خادم العرض والنوافذ (Desktop) Hyprland Wayland 0.47+ حركات زجاجية ناعمة، مساحات عمل لانهائية، ودعم كامل للشاشات المتعددة والـ HiDPI.
مثبت النظام (Installer) Calamares 3.x GUI مثبت رسومي بالكامل يدعم اللغة العربية، تقسيم الأقراص التلقائي، والـ Dual Boot.
نظام الملفات (Filesystem) Btrfs (@, @home, @snapshots) لقطات فورية خفيفة مع حماية النظام من أي عطل في التحديثات.
نظام الصوت (Audio System) PipeWire + WirePlumber صوت نقي فائق الجودة متوافق مع كافة برامج البث والمونتاج ومكبرات البلوتوث.
إدارة الذاكرة (Memory Tuning) systemd-zram-generator مساحة Swap افتراضية مضغوطة داخل الرام تمنع التهنيج تماماً عند امتلاء الذاكرة.
الطرفية وموجه الأوامر (Shell) Kitty + Zsh + Starship محاكي طرفية مسرّع ببطاقة الشاشة (GPU-Accelerated) مع خطوط نيرد فونت الحديثة.

EASY INSTALLATION & DOWNLOAD

خيارات تحميل وتثبيت NooreldeanOS

سواء كنت تريد أسطوانة حية كاملة للتثبيت السهل بنقرات زر، أو تثبيت حزمة التوزيعة فوق نظام Arch لديك، كل شيء مهيأ بسلاسة.

installation manager

الخيار الموصى به: أسطوانة Live ISO متكاملة وجاهزة للحرق على فلاشة USB: إقلاع فوري لتجربة النظام حياً بدون لمس الهاردسك، مع مثبت Calamares الرسومي الشهير ونواة linux-zen فائقة الأداء.

# للحرق عبر التيرمينال بنظام Linux (استبدل sdX بمسار الفلاشة):
sudo dd bs=4M if=NooreldeanOS-x86_64.iso of=/dev/sdX status=progress oflag=sync ⬇️ صفحة تحميل الـ ISO المباشر

1. مثبت Calamares الرسومي

تثبيت سهل بنقرات زر بدعم كامل للعربية وتقسيم القرص أو التثبيت بجانب ويندوز (Dual Boot).

2. نواة linux-zen للألعاب

مسرعة لتقليل زمن استجابة الإطارات وضمان أقصى أداء ممكن للألعاب وصناعة المحتوى.

3. إقلاع مباشر وتجربة حية

اختبر واجهة النظام بالكامل مباشرة من الفلاشة مع كافة التأثيرات والبرامج قبل اتخاذ قرار التثبيت.

4. كشف Nvidia و AMD التلقائي

تعريفات وباتشات متوافقة جاهزة للإقلاع سواء كانت بطاقتك Nvidia حديثة أو معالجاً مدمجاً.

5. شاشة إقلاع Plymouth

ثيم Dark Glow المتوهج بإقلاع فوري وسلس بدون وميض (Flicker-Free Booting).

6. حماية Btrfs Snapshots

تهيئة تلقائية لتقسيم Btrfs مع مجلدات فرعية لحماية بياناتك من أي تحديث مفاجئ.

لو كنت تستخدم بالفعل Arch Linux أو إحدى التوزيعات المبنية عليه وتريد تحويل واجهتك إلى بيئة NooreldeanOS بالكامل:

git clone https://github.com/coach-nooreldean/NooreldeanOS-Dotfiles.git ~/NooreldeanOS-Dotfiles && cd ~/NooreldeanOS-Dotfiles && bash install.sh

1. فحص النظام واليوزر

تعديل مسارات ملفات الكونفيج تلقائياً لتناسب مجلدك الشخصي دون تعديل يدوي.

2. نسخ احتياطي تلقائي

حفظ ملفاتك وإعداداتك السابقة في مجلد ~/.NooreldeanOS-backup مؤرخ وآمن.

3. حزم Pacman + Yay

تثبيت بيئة Wayland والحزم المطلوبة مع أدوات Rofi و Waybar و Pywal بسلاسة.

4. تفعيل الخدمات الفورية

ضبط ZRAM والجدار الناري وجلسة Hyprland للعمل المباشر فور تسجيل الخروج.

للمحترفين: إذا قمت بالإقلاع من أسطوانة Arch Linux الرسمية الخام وتريد بناء نظام NooreldeanOS عبر الإنترنت من الصفر:

bash <(curl -sL https://raw.githubusercontent.com/coach-nooreldean/NooreldeanOS-Dotfiles/main/start.sh)

1. تقسيم القرص Btrfs

تهيئة قطاعات EFI والتقسيم الذكي للأقراص بأمان وسرعة.

2. تنزيل النواة

تثبيت نواة Linux-Zen وتحديث مستودعات الحزم بسرعة البرق.

3. إعداد الحساب

ضبط الشبكة والوقت وإنشاء حسابك الشخصي مع صلاحيات sudo في خطوة واحدة.

4. إقلاع مباشر

إعادة تشغيل فورية والدخول في واجهة SDDM وشاشة القفل الزجاجية.

إذا أردت إلغاء التثبيت واسترجاع إعداداتك السابقة بالكامل من النسخة الاحتياطية:

./uninstall.sh

يقوم السكربت بسؤالك عما إذا كنت تفضل الإبقاء على تطبيقاتك الشخصية أو إزالتها واستعادة ملفات التكوين الأصلية تماماً.

HELP & FAQ

الأسئلة الشائعة حول التوزيعة

إجابات شاملة ومباشرة على كل ما يهمك معرفته عن NooreldeanOS.

هل NooreldeanOS توزيعة لينكس كاملة أم مجرد ثيم؟ ➕
NooreldeanOS هي توزيعة لينكس كاملة ومستقلة مبنية على Arch Linux، تأتي بأسطوانة Live ISO قابلة للإقلاع المباشر ومثبت Calamares الرسومي الشهير ونواة Linux-Zen المسرّعة. كما نوفر خيار تثبيتها كطبقة نظام فائقة على توزيعات Arch الحالية لمن يفضل ذلك.
هل تدعم التوزيعة التحديثات المتجددة (Rolling Release)؟ ➕
نعم! التوزيعة تعتمد بشكل مباشر على مستودعات Arch Linux الرسمية ومستودع AUR الضخم، مما يعني أن نظامك سيحصل دائماً على أحدث تعريفات العتاد والأنوية والبرامج باستمرار وبدون الحاجة لإعادة التثبيت كل فترة.
هل يمكن تثبيتها بجانب ويندوز (Dual Boot) بأمان؟ ➕
نعم بكل تأكيد! مثبت Calamares الرسومي المدمج في أسطوانة الـ ISO يحتوي على خيار صريح لتثبيت NooreldeanOS بجانب ويندوز (Install alongside) دون المساس بملفاتك أو بارتشن الـ C، مع إضافة نظام ويندوز تلقائياً إلى قائمة إقلاع GRUB.
ماذا يحدث إذا حدث خطأ أثناء تحديث النظام أو تعطل الإقلاع؟ ➕
بفضل معمارية Btrfs وأداة noor-snap، يقوم النظام بحفظ لقطات فورية تلقائية. إذا واجهت أي مشكلة، يمكنك ببساطة استرجاع أي لقطة سابقة خلال ثوانٍ من داخل النظام عبر Super + Shift + S أو اختيار اللقطة مباشرة من شاشة إقلاع GRUB!
هل أحتاج لتثبيت تعريفات Nvidia يدوياً؟ ➕
لا، نظام التوزيعة مزود بـ GPU Auto-Tuning يتعرف تلقائياً على كروت Nvidia و AMD و Intel ويضبط كافة متغيرات Wayland المطلوبة لمنع أي تمزق في الشاشة أو مشاكل في مؤشر الفأرة.
كيف أغير مواقيت الصلاة لتناسب مدينتي؟ ➕
يمكنك تعديل إحداثيات خط الطول والعرض أو اسم دولتك ومدينتك من خلال ملف ~/.config/waybar/scripts/prayer_times.sh في ثوانٍ معدودة.
كيف أضيف خلفياتي الخاصة لمبدل Super + W؟ ➕
ضع أي صور أو خلفيات بدقة عالية داخل مجلد ~/wallpapers/ وستظهر فوراً في شبكة الـ Rofi عند الضغط على Super + W وتتولد منها ألوان النظام تلقائياً.
